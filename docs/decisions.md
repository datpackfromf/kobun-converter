- 2026-11-19 辞書の basis（根拠）は、サブエージェントが古語辞典の標準的な語義と有名な用例の知識から書いたもので、外部の辞書サイトとの照合はしていない（未確認）。status=confirmed は「根拠を文章で書けた」の意味にとどまる — 照合の手段（ライセンスの明確な古語辞典データ）がなく、時間内に人手で引けないため。README と review.md に明記する。
- 2026-11-19 表層形の語彙は、トークンの境目で始まり終わる一致だけを使う。接続詞・感動詞は文頭（または読点の後）だけ、カタカナ語は直後がカタカナでないときだけ、形容詞の連用形と同じ形の副詞（早く・すごく）は直後が助動詞・助詞・非自立語でないときだけ当てる — 「向こう」の中の「こう」、「ペンギン」の中の「ペン」、「早くない」の「とくない」を防ぐため。
