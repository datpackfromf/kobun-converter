# 語彙辞書の項目の形

各分野のファイル `data/vocab/<分野>.json` は次の形の配列（JSON、UTF-8）。

```json
[
  {
    "modern": "面白い",
    "reading": "おもしろい",
    "match": "lemma",
    "kobun": "をかし",
    "kobunModern": "おかし",
    "kobunReading": "をかし",
    "pos": "adjective",
    "class": "シク",
    "basis": "古語「をかし」は趣がある・興味深い・こっけいだの意（枕草子に多用）。現代語の『面白い』の中心義（興味深い）に対応。",
    "status": "confirmed",
    "note": ""
  }
]
```

| 欄 | 内容 |
|---|---|
| modern | 現代語。`match: "lemma"` なら解析器（IPADIC）の原形と同じ形（例: 面白い・驚く・びっくりする は「びっくり」(名詞サ変接続)＋する なので modern は「びっくりする」と書き lemma 照合でなく surface 照合にする）。`match: "surface"` なら入力に現れる表層形そのもの（例: とても・本当に・早く・だから）。 |
| reading | modern のひらがな読み（現代仮名遣い）。 |
| match | `lemma`（動詞・形容詞・形容動詞語幹を原形で引く）か `surface`（表層形の文字列で最長一致）。 |
| kobun | 古語の原形（終止形）。歴史的仮名遣い。漢字は使ってよい（漢字の部分は出力でそのまま出る）。 |
| kobunModern | kobun と同じ表記で、仮名の部分だけを現代仮名遣いにしたもの（をかし→おかし、言ふ→言う、いと→いと）。 |
| kobunReading | kobun 全体のひらがな読み（歴史的仮名遣い）。 |
| pos | adverb / adjective / adjectival_noun（現代語が形容動詞「〜だ」で、modern は語幹だけ: 残念・不思議）/ verb / noun / conjunction / interjection / katakana |
| class | 古語の活用の種類。形容詞: ク / シク。形容動詞（古語側がナリ活用）: ナリ。動詞: 四段 / 上一段 / 上二段 / 下二段 / カ変 / サ変 / ナ変 / ラ変。活用しない語は null。**古語側（kobun）の活用**を書く。 |
| basis | 根拠。古語の意味と、その対応が成り立つ理由。可能なら古典の用例か出典（古語辞典名・Wiktionary 等）を書く。 |
| status | `confirmed`（根拠が書けた）か `review`（根拠が書けない・意味のずれが大きい・自信がない）。 |
| note | 意味のずれ・使い方の注意（なければ空文字）。 |

注意:
- 現代語と古語で意味が変わった語（例: 古語「やがて」＝すぐに、「あさまし」＝驚きあきれる、「うつくし」＝かわいい、「ありがたし」＝めったにない、「おどろく」＝はっと気づく・目が覚める）は特に注意し、note に書く。
- 1つの modern に複数の古語候補があるときは、もっとも一般的な1つだけを入れる。
